# Bundled terminal fonts

These unmodified typefaces are included in `app/src/main/assets/fonts/` and
can be selected in Visual settings.

| Font | Upstream | License |
|---|---|---|
| JetBrains Mono | [JetBrainsMono](https://github.com/JetBrains/JetBrainsMono) | SIL Open Font License 1.1 |
| Hack | [Hack](https://github.com/source-foundry/Hack) | MIT; includes DejaVu/Bitstream Vera notices |
| Fira Code | [FiraCode](https://github.com/tonsky/FiraCode) | SIL Open Font License 1.1 |
| DejaVu Sans Mono | [DejaVu Fonts 2.37](https://github.com/dejavu-fonts/dejavu-fonts/releases/tag/version_2_37) | Bitstream Vera Fonts License / DejaVu public-domain changes |
| Ubuntu Mono | [Ubuntu Fonts](https://github.com/google/fonts/tree/main/ufl/ubuntumono) | Ubuntu Font Licence 1.0 |

The terminal also includes Cascadia Mono as its fallback font; its SIL Open Font
License notice is `app/src/main/assets/fonts/Cascadia-OFL.txt`.
